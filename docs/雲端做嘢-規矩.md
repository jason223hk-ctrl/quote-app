## 二、每次開工要行嘅四步

```
npm ci          # ⛔ 唔好 npm i —— 要跟足 package-lock
npm run gate    # typecheck → lint → test → build
npm run ui:check
```

⭐ `ui:check` 而家喺 fresh clone 都行得到，兩個理由：

1. **原型入咗 repo**（2026-09-05 起，見 `docs/原型-stage57-autoupload.html`）——
   之前四條路全部喺 repo 外面，fresh clone 揾唔到個原型就即刻死。
2. **搵瀏覽器嗰度識試部機本身嗰個 chromium**（2026-09-05 加）——
   雲端部機有 chromium，但 Playwright 因為版本號對唔上而用唔到自己嗰個，
   之前要人手加 `CHROMIUM_PATH` 先行到。⚠️ 一個要靠人記得嘅步驟，遲早會漏。

⛔ 之前佢淨係喺 Jason 部機行到 —— 即係「對數」嗰關會靜靜咁跳咗。
⚠️ 呢兩樣都唔係「順手執靚」，係擋住同一件事：**一關驗唔到，就會有人當佢冇事咁跳過。**

**四步嘅第四步：⛔ 開 PR，唔好 push 上 `main`。**
