## 三、量緊咩

`tools/ui-check/measure.mjs` 入面 `SCREENS` 逐項列住
「真 app 選擇器 ↔ 原型選擇器」，每對量：

- 闊、高、距左、距右
- 字級、字重、行高、顏色
- 四邊內距、圓角、邊粗
- 係咪襯線體

容忍 1.5px（sub-pixel 同字型 hinting），其餘一律要一模一樣。

三個模式避開假差異：
`font`（樣本文字唔同，唔量尺寸）、`box`（冇字，唔量字）、`nosize`（內容行數唔同，唔量高）。

## 五、裝嘢

`playwright` 已經喺 `devDependencies` 入面，`npm i` 就有。
瀏覽器本身要再行一次（一部機一次就夠）：

```
npx playwright install chromium
```

⛔ **兩樣都要喺 Mac Terminal 度做，唔好經 Cowork。**
Cowork 個 mount 行喺 linux-arm64 VM，喺嗰邊 `npm i` 會將
`package-lock.json` 換成 Linux 版，Mac 就 build 唔到
（`Cannot find module @rollup/rollup-darwin-arm64`）。

## 六、⚠️ 陷阱
