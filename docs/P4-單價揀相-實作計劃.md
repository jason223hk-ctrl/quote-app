## 3. P4.5 揀相

入口（第一稿）：工程頁第五行「揀相」。
⚠️ **呢個入口係暫定** —— P5 做咗之後，佢好可能變成「出報價 → 揀相 → 出 PDF」流程入面嘅一步，⛔ 唔係獨立一行。

### 3.1 畫面
- 上面一句：`揀中的相片會放入報價 PDF。未揀的相片仍然保留在 Drive，不會刪除。`
  ⭐ ⛔ 唔准慳呢句 —— 同事最易誤會「唔揀＝刪咗」。
- 按來源分組：**環境相** 一組，跟住**每棵樹**一組（`樹 {樹牌}`）
- 每格右上角一粒圈，撳一下打剔；揀中嘅有深綠框
- 每格左下角細字：`全景相 01`、`清理樹冠 03`、`環境 01`
- 底部固定一條：`已揀 N 張` ＋ `完成`（⛔ 唔使碌返上去都知揀咗幾多）
- 冇相：`尚未拍攝任何相片`
- 揀完返工程頁，嗰行顯示 `已揀 N 張` ／ `尚未揀相`

### 3.2 ✅ 自動排（Jason 08-24 拍板）
⛔ 唔做拖動排序。次序固定：

```
環境相 → 按樹牌順序，每棵樹入面：全景相 → 工序（照 P3e §4.4 嗰個固定次序）
```

⭐ 點解：每張報價格式一致，⛔ 唔使每次執位；手機拖動亦都難撳。
