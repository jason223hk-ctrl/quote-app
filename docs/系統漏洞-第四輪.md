# quote-app 十個漏洞（第四輪）

⭐ 今次角度：**數字、文字、同對唔對得返**。
前三輪查過流程、人同角色、每個工程嘅獨立性。今次專門查
「打錯嘢會點」、「個數字信唔信得過」、「PDF 講嘅嘢同入面啲相對唔對得返」。

⛔ 每一條都係喺原型真係行過一次量返嚟嘅，唔係睇 code 估。
⛔ 我冇改過任何嘢，呢份純粹係報告。

## 1. 抬頭嘅「樹木數量」唔跟你揀嘅樹

**量到**
```
成個工程 5 棵樹，抬頭寫「修剪 3 棵」
喺匯出頁淨係剔返 1 棵樹（樹 1）
→ 抬頭照樣寫「修剪 3 棵」
→ PDF 入面實際得 3 張相，全部屬於樹 1
```
**點解出事**
客戶收到份 PDF，抬頭話有 3 棵樹，揭到尾得一棵。佢會問「另外兩棵呢？」
你自己都答唔到，因為個數字根本唔係講緊呢份 PDF。

## 2. 冇揀工序嘅樹，完全唔入數

**量到**
```
5 棵樹嘅工序：樹1=[修剪,疏枝] 樹2=[] 樹3=[] 樹4=[修剪] 樹5=[修剪,近攝]
exCountText() = "修剪 3 棵"
```
**點解出事**
樹 2、樹 3 憑空消失。如果同事喺現場影咗相但仲未揀工序（好正常，趕住走），
份 PDF 就會出佢哋嘅相，但抬頭話冇呢兩棵樹。
⚠️ 第三輪第 10 條處理過「冇工序嘅樹相底空白」，⛔ 但個數字呢邊冇跟住修。

## 3. 單價設定打錯字，會靜靜雞變 $0

**量到**
```
攀樹師原本 $2,000
打「abc」 → 單價變 0 → 成本出「攀樹師 1 人 × 1 日   $0」
打「-500」→ 單價變 500（負號被抹走，變咗正數）
留空      → 單價變 0
```
**點解出事**
$0 唔會彈任何嘢出嚟。你照計、照報價、照做，做完先發現攀樹師嗰嚿成本冇計過。
⛔ 呢個係全公司一套嘅設定，一個人打錯，之後所有新工程都錯。

## 4. 加成打「5.5%」會變 55%

**量到**
```
markupPct() 抹走所有唔係數字嘅字元
打「5.5」 → 55
打「-20」 → 20
成本 $18,000：想加 5.5% 收 $18,990，實際出 $27,900
```
**點解出事**
差 $8,910。而且畫面上「5.5」睇落好正常，唔會知個數係點嚟。

## 5. 人數同日數冇上下限

**量到**
```
地面工人打「-3」    → 成本明細出「地面工人 -3 人 × 1 日   $-3,000」
地面工人打「999999」→「地面工人 999999 人 × 1 日   $999,999,000」
```
**點解出事**
負成本會將總數拉低，而且會抵銷其他項目。手指撳錯一個「-」就中招。

---

## 6. 日數留空，人手照計但 Overhead 唔計

**量到**
```
日數留空、攀樹師 1、地面工人 2
→ 攀樹師 1 人 × 1 日   $2,000
   地面工人 2 人 × 1 日 $2,000
   （冇 Overhead）
   總 $4,000
```
**點解出事**
同一個「未填日數」，人手當佢係 1 日，Overhead 當佢係 0 日。兩套規矩。
⚠️ Overhead 唔計係當初特登嘅（唔想新工程一開就見到 $2,000），
⛔ 但人手嗰邊冇跟同一套邏輯，所以個總數係一個似真非真嘅數。

## 7. 「未計 N 項」嘅解釋，喺手機睇唔到

**量到**
```
剔咗一項逐次報價之後：
  畫面見到     "$78,750 ⚠"
  解釋文字放喺  title="有 1 項逐次報價未計入成本，實際要收多過呢個數"
```
**點解出事**
`title` 係電腦滑鼠停低先出嘅提示。⛔ 手機用手指撳唔出。
即係同事喺現場淨係見到一個 ⚠，完全唔知係咩事，最大機會當佢冇嘢。

## 8. 工程名同備註冇擋 HTML

**量到**
```
工程名打「<b>爆</b>格測試」→ 抬頭真係變咗粗體（插咗個 <b> 落去）
備註打「<img src=x> 斷咗<br>行」→ PDF 相底真係插咗個 <img>
```
**點解出事**
⛔ 呢個唔係保安問題（自己人用自己 app）。真正嘅風險係**食字**：
備註入面打個「<」，後面成段字會唔見咗，而你唔會知，因為畫面唔會報錯。
樹木備註成日會寫「<3m」、「傾斜 <15度」呢類嘢。

## 9. 今日日期寫死咗

**量到**
```
TODAY = '2026-08-25'（寫死喺 code 入面）
真實今日 = 2026-08-28
新工程預設日期 = 2026-08-25 ← 錯咗 3 日
```
**點解出事**
「報咗 N 日」全部少計。放耐咗，就係差成個月。
⚠️ 呢個係樣板刻意寫死嘅（等測試有固定結果），⛔ 但正式版一定要換返真日期，
所以要留一條喺清單上面，唔好等到上線先發現。

## 10. 匯出頁可以剔住一張相都冇嘅樹

**量到**
```
匯出頁：揀咗 5 棵樹
樹 2、樹 3 一張相都冇（全景 0、工序 0）
→ PDF 出嚟得 3 棵樹嘅相
→ 匯出頁冇任何提示話你知有兩棵係空嘅
```
**點解出事**
你以為份 PDF 有 5 棵樹。撳落去先發現得 3 棵，或者更差 —— 客戶先發現。

**附帶（同一版）**：搜尋工程嗰個日期範圍，開始日期揀到大過結束日期，
app ⛔ 唔攔，直接出零個結果，唔會話你知係你揀反咗。

# 我覺得最急嗰三條

**第 3 條（單價打錯變 $0）** —— 因為佢係全公司一套，一個人錯，之後全部工程錯，
而且完全唔會叫。呢條係唯一一條會令你**報少咗價、蝕住做**嘅。

**第 1 條（抬頭數量唔跟揀嘅樹）** —— 因為呢個係直接送到客手上嘅錯，
而且你冇得解釋。

**第 7 條（tooltip 手機睇唔到）** —— 因為「逐次報價未計入」呢個提示係我哋特登加，
用嚟防止報漏成部吊雞。而家個提示喺現場等於唔存在，即係嗰個保護冇咗。
