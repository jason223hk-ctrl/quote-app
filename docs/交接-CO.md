**功能**
- 每張相一個備註（40 字），會印落 PDF 相底。
- 客戶簿：獨立一本，揀咗就**複製一份**入工程。⛔ 之後改客戶簿唔會影響已填咗嘅工程。
- 搜尋：彈出 dialog，日期範圍／工程名稱／建立人。日期揀反咗自動掉轉。
- 建立人：記低邊個開嘅工程。
- 兩個角色：現場、辦公室。「已中標」需要辦公室權限。
- 已報價工程出「報咗 N 日」。⛔ 首頁唔動，只喺工程列表出。
- 成本明細 ＋ 加成％ → 報價價錢（加成收得小數，5.5% 就係 5.5%）。
  ⛔ 成本同收客價**永遠唔上 PDF**。

**計價（全部係成本）**
- 地區三選：新界／九龍／香港、大嶼山。
- 日／夜真係影響價錢。夜晚價⛔ 唔分區，全港一個數。
- 夾車：**架數 × 價**，⛔ 唔乘日數。9 噸碎垃圾冇數量欄。
- 人手、吊雞、升降台：乘日數。
- Overhead 自動計入，跟日數，日數留空當一日。
- 「逐次報價」項目（輝哥 100T、升降台其他、起樹頭兩項）⛔ 唔可以當 $0，
  要出返一行「逐次報價，未計入」。

**PDF**
- A4 直度，一頁四張相，兩張一行。
- 相底：檔名 ＋ 工序（英文，一行寫晒）＋ 備註。
- 抬頭每頁都出：左邊標誌，右上角三行（工程名／日期／樹木數量），⛔ 三行齊頭靠左。
- 樹木數量數嘅係**今次匯出真係有相出嗰啲樹**，⛔ 唔係成個工程有幾多棵。
- 環境相⛔ 唔入 PDF。

**行為**
- 全部輸入即時儲存，⛔ 冇「儲存」掣（只有新增工程嗰次有「建立工程」）。
- 每個工程完全獨立：揀咗嘅項目、架數、人手、客戶、匯出揀咗邊幾棵樹，
  ⛔ 全部跟工程走，轉工程唔會殘留。
- 「已中標」之後⛔ 唔可以轉返「待報價」或「已報價」。
