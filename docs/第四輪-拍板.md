### 補做（Jason 2026-08-28 第二次講）

**「2026-08-22 用返呢個格式」＋「匯出既日期都用日曆」**

⚠️ 原生 `input[type=date]` 顯示咩格式 ⛔ 改唔到 —— 佢跟部機語言，英文機出 `08/22/2026`。
所以⛔ 唔可以淨係用原生格。

⭐ 做法（兩個日期格都係咁）：
```
<div class="datefld">
  <input type="text" class="dshow" readonly>   ← 面頭，永遠寫 2026-08-22
  <input type="date" ...>                      ← 上面，透明、鋪滿成格
  <svg class="dcal">                           ← 畫返個日曆圖示
</div>
```
- 顯示格 `readonly` ＋ `pointer-events:none`，⛔ 打唔到字，淨係睇。
- 真日期格 `opacity:0` 鋪滿成格，撳邊度都係撳緊佢 → 出原生日曆。
- 電腦 Chrome 淨係撳個圖示先自動開，所以加咗 `openDatePicker()` 叫 `showPicker()`。
  ⛔ 要包 try —— 撳正個圖示嗰陣佢已經開緊，再叫一次會 throw。
- ⛔ 每次用程式改真值之後一定要叫 `paintDates()`，否則面頭嗰格唔會跟住郁。
  已經喺 `showSite()`、`openNew()`、`showPdf()` 三個位補咗。

⚠️ **匯出頁個日期而家係日曆，即係打唔到「2026-08-22 至 2026-08-29」呢類範圍。**
⛔ 呢個係跟足你講嘅結果。想打得返範圍就要加多一個「至」日期格，同我講。

⭐ 順手拆走兩處仲寫死住 `'2026-08-25'` 嘅 fallback，改用 `TODAY`。
