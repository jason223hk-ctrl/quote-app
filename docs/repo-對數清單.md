# 二、計價（⛔ 一條都唔可以錯，錯咗就報錯價）

1. 單價表全部係**成本**，⛔ 唔係收客價。
2. 地區三選：新界／九龍／香港、大嶼山。
3. 日／夜真係影響價錢。夜晚價⛔ 唔分區。
4. 夾車 ＝ **架數 × 價**，⛔ 唔乘日數。9 噸碎垃圾冇數量欄。
5. 人手、吊雞、升降台 ＝ 乘日數。
6. Overhead 自動計入，跟日數，留空當一日。
7. 「逐次報價」項目⛔ 唔可以當 $0，要出返一行「未計入」。
8. 加成收得小數（5.5% 就係 5.5%）。
9. **單價快照**：工程建立嗰陣影印低成套單價。⛔ 之後改公司價唔准追溯。
10. ⛔ 成本同收客價**永遠唔上 PDF**。

# 三、相片同 Drive（⛔ 最易出事嗰組）

1. 相片 identity 靠 `appProperties.quotePhotoId`，⛔ **永遠唔准靠檔名**。
2. 編號 `NN = 2 × seq − 1`，每（樹 × 分類）獨立一串。
3. 「其他」工序檔名 token ＝ `Other`，⛔ 唔係 `Other-1`。
4. 中咗標 → **搬成個子資料夾**（一次 `files.update`，addParents／removeParents），
   ⛔ 唔准逐張相 PATCH。
5. 删相 ＝ 真删，入 Google 垃圾桶。⛔ 唔留底。
6. 同一棵樹同一時間⛔ 只准一部機影。
7. 上載前壓縮 ＋ 配額警告。⛔ 15GB 同 Gmail、Google Photos 共用。
8. 對數 ＝ Drive `files.list` ＋ DB `select`，比 id、size、`quotePhotoId`。

# 四、PDF

1. A4 直度，一頁四張相，兩張一行。
2. 相底：檔名 ＋ 工序（英文，一行寫晒）＋ 備註。
3. 抬頭**每頁**都出：左邊標誌（連字，高 40px），右上三行齊頭靠左。
4. 樹木數量數「今次真係有相出嗰啲樹」，⛔ 唔係成個工程幾多棵。
5. ⛔ 冇簽名格、⛔ 冇公司名文字、⛔ 冇價錢、⛔ 冇環境相。
6. 相片次序：按樹牌 → 每棵樹全景相 → 工序。
7. 匯出之後⛔ 唔問「轉做已報價」。

# 五、狀態同權限

1. 三個狀態：待報價 → 已報價 → 已中標。
2. 「已中標」需要辦公室權限，而且要彈確認框，
   ⛔ 唔准寫「確定嗎」，要寫明搬咩、搬去邊、同事即刻見到、**冇得返轉頭**。
