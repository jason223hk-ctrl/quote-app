## 第三章 相片點存（已批）

### 壓一次，兩邊存同一份

**長邊 2048、JPEG 85。R2 同 Drive 存嘅係同一份 bytes。**

**呢個同 tree app 唔同，係特登。**
tree app 個 Drive 存原圖、另一邊存壓縮版，**兩邊 bytes 唔同**。
報價相**唔係交付物**，唔使留原圖；統一咗之後**同一個 `sha256`**，
兩邊對數簡單一半。

### 兩份副本

- **R2** —— app 日常讀寫嗰份
- **Drive** —— 第二份，保命

**契約：任何時候至少兩份。**
⛔ **未上到 Drive 嗰啲相，永遠唔准刪佢 R2 嗰份。**

### 上傳條路（六步）

1. **影完即刻寫落部機**，讀返出嚟對 `size` 同 `sha` —— 對到先算存到
2. **問自己個 Worker 攞一條上傳網址**
3. **部機直接上 R2 bytes，唔經 Worker**
4. **讀返出嚟對 `size` 同 `sha`** —— 對到先當已入 R2
5. **Worker 背景抄一份去 Drive**，成功先記低
6. **全部做完先叫「已同步」**

⛔ **bytes 唔准經 Worker 中轉。**
一個 145 張相嘅工程應該**問一次攞晒**，唔係問 145 次。

**影相嗰刻定死一個編號，每次重試用返同一個。**

### 檔名

**R2：**

```
用戶id/影相編號.jpg
```

**Drive 根資料夾：`Quote App Photos`**（Jason 2026-08-16 定）。

命名風格跟返 tree app 個 `Sylvan Tree Photos`
（出處：tree app `worker/wrangler.toml:24` 嘅 `DRIVE_ROOT_FOLDER_NAME`），
咁樣**兩個 app 喺 Drive 度並排，一眼睇得出邊個係邊個**。

**結構：根資料夾下面，一個工程一個資料夾**，同 tree app 一樣
（tree app 實際係 `工作日期_工程名`，例如 `2026-07-28_香港大學_Order130`；
出處 `worker/src/worker.mjs:1590-1592`）。

**Drive 相名：** 跟 tree app 同一條規則，四段用底線接埋：

```
樹編號_類別_兩位序號_Before或After.jpg
```

真例子（全部由 tree app 嘅測試逐個釘死）：

```
T758_00_Tree Tag.jpg
T1_Whole View_01_Before.jpg
T1_Crown Cleaning_01_After.jpg
T007_Crown Thinning_01_Before.jpg
TARZAN ISLAND_Close Up_02_After.jpg
```

- **樹編號**：用家自己打，**原文保留**，只做檔名清洗。
- **清洗規則照抄 tree app**（`src/domain/photoFilename.ts:10-14`）：
  `\ / : * ? " < > |` 同控制字元 → `_`，trim，最多 80 字，空就 `untitled`。
  例：`T/7:58*?` → `T_7_58__`
- **序號兩位數**（`01`、`02`、…）。
