## 4. ⛔ 規格（Jason 2026-08-23 逐項拍板，樣板已驗）

### 4.1 樹木清單

- 每張樹卡：**上面一行樹牌號**（等寬字），**下面一行「工序 · N 張相」**
- ⛔ 冇相機掣、⛔ 冇品種
- 撳張卡直接入樹
- 右下角一個**圓形 `＋`**，⛔ 冇「加樹」兩個字

### 4.2 加樹

撳 `＋` → 彈出卡（**由頂彈出**，⛔ 唔係由底掃上）：

1. **樹牌號**輸入欄（規則見 §4.5）
2. 三個大掣：**修剪 ›** ／ **移除** ／ **其他 ›**

**修剪第二頁**：清理樹冠 · 疏枝 · 縮減樹冠 · 提升樹冠
**其他第二頁**：起樹頭 · 拉索加固 · 近景 · **其他 ›**
**「其他」第三層**：一個輸入欄打低係咩處理方法 → 存 `mitigation_other`

**揀完工序就直接入咗棵樹。**
⛔ 冇「唔揀工序」嘅出口 · ⛔ 冇品種 · ⛔ 唔顯示英文 token

### 4.3 樹木頁

- 啡色頂：`‹` · **樹牌號** · 右上 `⋯`；下面一行工程名
- ⛔ **撳樹牌冇任何功能**
- 撳 `⋯` → 一張卡：**樹牌**（輸入欄）→ **🗑 刪除** → **取消 ／ 儲存**
  ⛔ 冇中間層選單、⛔ 冇品種

### 4.4 相格

**排序**：全景相永遠第一，工序按固定次序自動排 —— ⛔ 唔理揀嘅先後：

```
清理樹冠 → 疏枝 → 縮減樹冠 → 提升樹冠 → 起樹頭 → 拉索加固 → 近景 → 其他
```

⚠️ **「移除」唔喺 Jason 個清單度**，暫時擺喺提升樹冠之後、起樹頭之前（docs 次序）。**未拍板。**

**每格**：標題 ＋ `拍攝` ／ `相簿`。有相就喺下面出一條**打橫相帶**：

- **一張卡放兩張細相**，第三張開始**向右掃**
- 得一張相都係**同一個 size**
- 每張相：右上 **✕**、左下**標籤**（例如「清理樹冠 03」）、右下 **◉ 標記**（P3d，未做）
- **撳細相放大全屏**，✕ 或者撳背景閂返
- ⛔ **唔顯示檔名** · ⛔ **唔顯示「已同步，兩份齊」**
- 仲上載緊：張相暗咗 ＋ 寫「上載緊⋯」；傳完就乾淨，乜字都冇

### 4.5 樹牌號規則（⛔ 照抄 tree app `src/domain/slice2.ts`）

**預設值**：⛔ **永遠係 `T`**（`useState('T')`）。刪得，可以打任何文字。
⛔ 唔准派流水號 —— 樹牌號係樹身上面實際嗰個牌。

**撞名 key（`normalizeTreeTag`）**：`/^([A-Za-z]*)(\d+)$/`
→ 大階字母 ＋ 去咗前置零嘅數字（留最少一位）。即 `T1`／`T01`／`T001`／`t1` 全部當同一個。
其他形狀（`TR-15`、`T758A`、中文）→ ⛔ 逐個字對。
範圍：一個工程入面唯一。撞到出**「此樹牌已存在」**，⛔ 加唔到。

**位數提醒（`checkTagFormatConsistency`）**：
`格式唔統一：此工程{X 系｜純數字}樹牌用緊 {N} 位數，請用一致格式`
⛔ 呢個係提醒，**唔阻你加**。兩個警告一次只出一個，撞名優先。

**儲存**：原文照存（trim），`normalizeTreeTag` 淨係做 key。
